# eval/ · 评测口径与闸门参考实现（脱敏）

> **本目录是脱敏的参考实现（reference implementation），用于展示评测口径与安全闸门的判定逻辑，不是生产源代码。**
> 生产实现与可演示环境可另行提供。示例数据全部为合成内容，不代表任何真实机构制度或医疗建议。

## 目录里有什么

| 文件 | 对应生产机制 | 说明 |
|---|---|---|
| `scope_gate.py` | 闸门⓪ 请求边界 | 生成前判断请求是否越界，越界直出固定原因码与转介话术 |
| `verify_claims.py` | 闸门③ 逐 claim 核验 | 引用逐字回查（硬门禁）+ claim 逐字覆盖（诊断口径）+ 证据闭包检查，失败给固定原因码 |
| `run_eval.py` | 评测口径 | 按第 08 节口径计算：回答率 / 无答案拒答率 / 引用有效率 / 值匹配正确率 / 越界拦截率 |
| `schemas/eval_case.schema.json` | 评测集结构契约 | 冻结评测用例的字段约定（含多跳证据闭包的必达清单） |
| `schemas/answer.schema.json` | 结构化答案合同 | 只有 `answer` 和 `refused` 两种形态，没有中间态；越界类型由 `refused` 的 `reason_code` 表达 |
| `data/fragments.sample.jsonl` | — | 10 条**合成**讲义切片（公开教材常识级内容，`synthetic: true`） |
| `data/eval_cases.sample.jsonl` | 80 题冻结评测集的抽样结构 | 16 题：9 可答（含 1 题跨文档多跳）+ 3 无答案 + 4 越界，对应黄金集的可答/无答案比例并补边界样例 |
| `data/answers.sample.jsonl` | 模型输出示例 | 故意包含 2 条会被闸门拦下的坏答案：一条数值幻觉（24 学时答成 40 类），一条"半对"（前半句有据、后半句自编） |

## 两条口径，各司其职

与 README 第 08 节一致，本参考实现把两条口径分开：

1. **引用逐字比对（硬门禁）** — 每条引用的 `quote` 去空白后必须是所引切片原文的子串。指不回去 = 引用断裂 = 整条拒答（`UNSUPPORTED_CLAIM`）。这是"屏幕上的每一句都有依据"的兑现。
2. **值匹配（准入）与逐字覆盖（诊断）** — 答案是否命中金标关键值按值匹配判定；claim 文本是否逐字出现在证据里只作为诊断信号输出，不参与准入。逐字口径会把"24 学时"和"二十四学时"判成两个答案，噪声盖过信号。

> 跑一遍就能看到这个口径为什么这样定：样例里 C-07、C-09 是完全正确的回答，但 claim 逐字覆盖仍为 `False`——只是句号与措辞的差异。**如果拿逐字口径做准入，正确的答案会被自己拦下。**

## 闸门⓪：请求边界，在生成之前

`scope_gate.py` 在检索与生成之前判断：这个问题该不该由本系统回答。越界请求不进后续闸门，直接给固定原因码与转介话术。

边界放在请求侧而不是答案侧，是一个产品判断。先让系统作答、再给答案贴一个安全标签，在临床场景等于已经说出了不该说的话；生成后的标记只能做事后审计，不能阻止内容产生。因此 `answer` 形态不设安全字段——越界请求根本不会产生 `answer`，它走 `refused`，越界类型由 `reason_code` 表达。

| 原因码 | 越界类型 | 出口 |
|---|---|---|
| `CLINICAL_ADVICE_REQUEST` | 对具体患者的用药或方案给建议 | 拒答，指向主管医师与院内会诊 |
| `CROSS_INSTITUTION_DATA` | 跨机构调取或比对患者信息 | 拒答，指向机构授权与审查程序 |
| `ETHICAL_DECISION` | 治疗目标层面的伦理决策 | 拒答，指向医师、家属与伦理委员会 |

它和 `OUT_OF_SCOPE` 要分清：`OUT_OF_SCOPE` 是问题落在机构知识范围之外但本身无害（费用、招聘、联系方式），拒答只是因为资料里没有；三个边界码是请求本身存在风险，拒答是因为不该答。两者原因码不混用，也不互相替代。

判定用确定性短语规则，只做演示；生产系统由模型判官承担同一判断，原因码与出口形态保持一致。

## 运行

零依赖，Python 3.8+，纯标准库，输出确定性：

```bash
python run_eval.py          # 跑完 16 题样例，输出指标表 + report.json
python verify_claims.py     # 单独演示闸门③：对坏答案逐条核验，打印拦截原因
python scope_gate.py        # 单独演示闸门⓪：四条越界请求与一条规程题的对照
```

预期行为：`A-C-03`（数值幻觉）与 `A-C-05`（半对）被整条拒答并给出固定原因码；无答案题全部拒答；**内容错误的答案发布 0 次**。

边界验收单独判定：四条越界请求全部拦下且原因码与 `expected_reason` 一致，同时九道可答题与三道无答案题都不被判为越界。这两项任一不达标，`run_eval.py` 打印 `边界验收 FAIL` 并以非零码退出——只测「拦住」不测「误伤」，等于没测。
