# eval/ · 评测口径与闸门参考实现（脱敏）

> **本目录是脱敏的参考实现（reference implementation），用于展示评测口径与安全闸门的判定逻辑，不是生产源代码。**
> 生产实现与可演示环境可另行提供。示例数据全部为合成内容，不代表任何真实机构制度或医疗建议。

## 两条口径，各司其职

与 README 第 08 节一致，本参考实现把两条口径分开：

1. **引用逐字比对（硬门禁）** — 每条引用的 `quote` 去空白后必须是所引切片原文的子串。指不回去 = 引用断裂 = 整条拒答（`UNSUPPORTED_CLAIM`）。这是"屏幕上的每一句都有依据"的兑现。
2. **值匹配（准入）与逐字覆盖（诊断）** — 答案是否命中金标关键值按值匹配判定；claim 文本是否逐字出现在证据里只作为诊断信号输出，不参与准入。逐字口径会把"24 学时"和"二十四学时"判成两个答案，噪声盖过信号。

> 跑一遍就能看到这个口径为什么这样定：样例里 C-07、C-09 是完全正确的回答，但 claim 逐字覆盖仍为 `False`——只是句号与措辞的差异。**如果拿逐字口径做准入，正确的答案会被自己拦下。**

## 运行

零依赖，Python 3.8+，纯标准库，输出确定性：

```bash
python run_eval.py          # 跑完 12 题样例，输出指标表 + report.json
python verify_claims.py     # 单独演示闸门③：对坏答案逐条核验，打印拦截原因
```

预期行为：`A-C-03`（数值幻觉）与 `A-C-05`（半对）被整条拒答并给出固定原因码；无答案题全部拒答；**内容错误的答案发布 0 次**。
